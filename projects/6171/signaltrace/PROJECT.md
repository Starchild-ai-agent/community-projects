# SignalTrace

## What
A browser-only pipeline observability workbench for validating JSON snapshots, comparing runs, and explaining zero-signal outcomes.

## Required env
None.

## How to start
Open `src/index.html` in any modern browser, or serve the project directory with a static file server.

## Outputs
Validation score, schema hints, change summary, and a traceable signal decision report.

## Troubleshooting
The app intentionally runs locally in the browser. Paste valid JSON objects or arrays; no data leaves the page.
